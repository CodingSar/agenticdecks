## What this area is about

This area asks how a cell is built so that chemistry, energy and information can work together in one unit. Biochemistry (layer 02) supplies the parts: enzymes, membranes, pumps, genes and signalling cascades. A cell is what happens when those parts are arranged in space. Membranes divide the volume into compartments with different chemistry; a protein skeleton holds the compartments in place and moves things between them; vesicles carry cargo without ever breaching a membrane; and a surveillance system checks every protein and destroys the failures. The unifying idea is that **the cell is an organised, self-maintaining structure held far from equilibrium**: every compartment is a gradient that costs energy, every piece of cargo carries an address, and the whole thing is rebuilt continuously from the inside.

```
   genes (02) --translation--> nascent protein --signal sequence--> compartment (organelles)
                                     |                                   |
                             chaperones fold it                   vesicles carry it
                             (quality control)                    (trafficking)
                                     |                                   |
                        misfolded -> proteasome / autophagy      along cytoskeletal tracks
                                                                  driven by motors
```

Read organelles first: it establishes the compartments and the rule that each one is a maintained gradient. The cytoskeleton adds mechanics and the tracks along which everything moves. Trafficking is the dynamic version of the organelle map, showing how the endomembrane system is one connected flow. Quality control closes the loop: a cell is not a finished object but a steady state of synthesis and destruction, and most degenerative disease is that steady state drifting.
