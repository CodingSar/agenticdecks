## Essence

A set is convex when it contains the segment between any two of its points. That single condition gives convex sets a property arbitrary sets lack: any point outside a closed convex set can be cut off from it by a hyperplane. Separation turns geometric questions into statements about linear functions, which is why convexity underlies duality in optimisation, the minimax theorem in games and the Hahn–Banach theorem in analysis. Three classical theorems, Carathéodory's, Radon's and Helly's, show that in ℝⁿ convexity questions about many points or sets reduce to questions about n + 1 or n + 2 of them.

## Core tenets

1. **Every point has a unique nearest point in a non-empty closed convex set.** Let C ⊆ ℝⁿ be closed, convex and non-empty, and x a point. A minimising sequence for the distance to x is Cauchy, by the parallelogram law and convexity (midpoints stay in C), and closedness keeps its limit p in C. Uniqueness also uses convexity: two nearest points would have a strictly nearer midpoint. Both hypotheses matter: an open ball has no nearest point to an outside point on its missing boundary, and an annulus has a whole circle of nearest points to its centre. The nearest point p is characterised by ⟨x − p, c − p⟩ ≤ 0 for all c in C, the angle condition.

2. **A point outside a closed convex set can be strictly separated by a hyperplane.** With p the nearest point to x, the hyperplane through the midpoint of x and p, perpendicular to x − p, has x strictly on one side and, by the angle condition, all of C strictly on the other. Two disjoint convex sets, one compact and the other closed, can likewise be strictly separated; without compactness the closed sets {y ≤ 0} and {y ≥ 1/x, x > 0} can be separated but not strictly.

3. **A closed convex set is the intersection of the half-spaces containing it.** Every point outside is cut off by some half-space, so nothing outside survives the intersection. At each boundary point there is a supporting hyperplane, touching C with C on one side. This dual description, by linear inequalities rather than points, is the geometric content of the [dual space](../../04-linear-algebra/01-vector-spaces-and-linear-maps/dual-spaces.md): convex sets are determined by the linear functionals bounded on them.

4. **Carathéodory's theorem: n + 1 points suffice to build any point of a convex hull.** The convex hull of S ⊆ ℝⁿ is the set of convex combinations of its points. If x is a convex combination of more than n + 1 points, these points are affinely dependent, so some combination with coefficients summing to 0 vanishes; sliding along it reduces one coefficient to zero while keeping the others non-negative. Repeating leaves at most n + 1 points.

5. **Radon's and Helly's theorems bound the combinatorics of intersections.** Radon: any n + 2 points in ℝⁿ split into two groups whose convex hulls meet, again from an affine dependence, splitting it by the sign of the coefficients. Helly: if every n + 1 sets in a finite family of convex sets in ℝⁿ have a common point, all of them do; the proof is induction using Radon's theorem. For infinite families compactness is needed: the half-lines [k, ∞) for k = 1, 2, 3, … meet in every finite subfamily but have empty intersection. Convexity is needed too: on the line, the sets {1, 2}, {2, 3} and {1, 3} meet in pairs but have no common point.

6. **Farkas's lemma: a linear system has a non-negative solution or a certificate that it does not.** For a matrix A and vector b, exactly one holds: Ax = b with x ≥ 0 has a solution, or some y has yᵀA ≥ 0 and yᵀb < 0. The first says b lies in the cone generated by the columns of A, a closed convex set; if it does not, the separating hyperplane gives y. This is the engine of [linear programming](../../14-applied-and-computational-mathematics/02-optimisation/linear-programming.md) duality and of the Karush–Kuhn–Tucker (KKT) conditions in [convex optimisation](../../14-applied-and-computational-mathematics/02-optimisation/convex-optimisation-and-duality.md).

7. **Separation extends to infinite dimensions and to games.** In normed spaces, separation of convex sets is the geometric form of the [Hahn–Banach theorem](../../09-advanced-analysis/03-functional-analysis/hahn-banach-and-baire-category.md), which needs the axiom of choice in general. Von Neumann's minimax theorem for two-person zero-sum [games](../../14-applied-and-computational-mathematics/05-games-decisions-and-finance/game-theory.md) follows by separating a convex set of achievable payoffs from a cone, and a support vector machine classifies data by finding the separating hyperplane with the widest margin.

## Key concepts

| Term | Meaning |
|---|---|
| Convex set | Contains the segment between any two of its points |
| Convex hull | The smallest convex set containing S; all convex combinations of points of S |
| Nearest-point map | Sends x to the unique closest point of a closed convex set |
| Separating hyperplane | A hyperplane with the two sets on opposite sides |
| Supporting hyperplane | A hyperplane touching a convex set at a boundary point, with the set on one side |
| Cone | A set closed under non-negative scaling; a convex cone is also closed under addition |
| Affine dependence | A vanishing combination of points with coefficients summing to 0, not all 0 |
| Helly number | n + 1 in ℝⁿ; the size of subfamilies that must be checked |

## Common misconceptions

- **"Any two disjoint convex sets can be strictly separated"**: Closed but unbounded sets can approach each other asymptotically; strictness needs one set compact.
- **"Helly's theorem holds for any family"**: Infinite families need compactness, and non-convex sets fail even in finite families.
- **"Farkas's lemma is an algebraic trick"**: It is separation of a point from a cone, read in coordinates.
