## Essence

Independence is the notion that probability adds to measure theory. Events A and B are independent when P(A ∩ B) = P(A)·P(B); random variables are independent when the σ-algebras they generate are, and an infinite family is independent when every finite subfamily is. Independence turns infinitely many trials into a product measure, and the two Borel–Cantelli lemmas then decide whether infinitely many events of a sequence occur. Kolmogorov's zero–one law adds a striking rigidity: an event fixed by the far future of an independent sequence has probability 0 or 1.

## Core tenets

1. **Independence is a product rule for σ-algebras, and pairwise is not enough.** σ-algebras 𝒢₁, …, 𝒢ₙ are independent when P(G₁ ∩ … ∩ Gₙ) = P(G₁)·…·P(Gₙ) for every choice of Gᵢ ∈ 𝒢ᵢ. For random variables it suffices to check the events {Xᵢ ≤ xᵢ}, because these form a class closed under intersection and the π–λ theorem extends the rule. Mutual independence is stronger than pairwise: toss two fair coins, with A = "the first is heads", B = "the second is heads" and C = "the coins agree". Each pair is independent, but P(A ∩ B ∩ C) = 1/4, not 1/8.

2. **Infinitely many independent variables exist on one space.** The binary digits of a uniform random number in [0, 1] are independent fair coin tosses, because each dyadic interval of length 2⁻ⁿ has probability 2⁻ⁿ. Splitting the digits into infinitely many infinite subsequences gives infinitely many independent uniform variables, and the quantile trick turns these into independent variables with any prescribed laws. This is the concrete content of the product measure.

3. **First Borel–Cantelli lemma: if ∑P(Aₙ) < ∞, then almost surely only finitely many Aₙ occur.** The event "infinitely many Aₙ occur" is ⋂_N ⋃_(n ≥ N) Aₙ, whose probability is at most ∑_(n ≥ N) P(Aₙ) for every N, the tail of a convergent series. No independence is needed. This is the standard way to turn a summable bound into almost sure convergence.

4. **Second Borel–Cantelli lemma: if the Aₙ are independent and ∑P(Aₙ) = ∞, then almost surely infinitely many occur.** By independence, the probability that none of A_N, …, A_M occurs is ∏(1 − P(Aₙ)) ≤ exp(−∑P(Aₙ)), using 1 − x ≤ e^(−x), and the sum diverges as M → ∞. Without independence the lemma fails: if every Aₙ is the same event A with P(A) = 1/2, the sum diverges, yet with probability 1/2 none occurs. A monkey typing forever produces any given text infinitely often: apply the lemma to disjoint blocks of keystrokes, which are independent.

5. **Kolmogorov's zero–one law: a tail event of an independent sequence has probability 0 or 1.** The tail σ-algebra 𝒯 = ⋂ₙ σ(Xₙ, Xₙ₊₁, …) holds the events unaffected by changing finitely many terms, such as "∑Xₙ converges". A tail event T is independent of (X₁, …, Xₙ) for every n, hence of the σ-algebra generated by all the Xₙ, which contains T. So T is independent of itself, P(T) = P(T)², and P(T) is 0 or 1. Without independence the law fails: if every Xₙ equals one fair coin X₁, the event {X₁ = 1} is a tail event of probability 1/2.

6. **The law says 0 or 1, but not which.** Deciding which takes real work. For independent random signs εₙ = ±1, the series ∑ εₙaₙ converges almost surely if and only if ∑aₙ² < ∞, so ∑ ±1/n converges with probability 1, while ∑ ±1/√n diverges with probability 1. In bond percolation on ℤ², where each edge is open independently with probability p, "there is an infinite open cluster" is a tail event, so its probability is 0 or 1; Harry Kesten proved in 1980 that the critical value of p is 1/2.

7. **Other zero–one laws trade the tail for symmetry.** "A simple random walk returns to 0 infinitely often" is not a tail event of the steps, since changing the first step shifts the whole path, but it is unchanged by permuting finitely many steps. The Hewitt–Savage zero–one law (1955) says that such exchangeable events of an independent, identically distributed sequence also have probability 0 or 1. In [ergodic theory](../../10-differential-equations-and-dynamics/04-dynamical-systems/ergodic-theory.md) the shift of an independent sequence is ergodic for the same reason: every shift-invariant event is a tail event.

## Key concepts

| Term | Meaning |
|---|---|
| Independent events | The product rule holds for every finite subfamily |
| Independent random variables | Random variables whose generated σ-algebras are independent |
| σ(X) | The σ-algebra of events {X ∈ B} for Borel sets B: the information in X |
| Pairwise independence | Every two members are independent; weaker than mutual independence |
| Aₙ infinitely often | The event ⋂_N ⋃_(n ≥ N) Aₙ that infinitely many Aₙ occur |
| Tail σ-algebra | ⋂ₙ σ(Xₙ, Xₙ₊₁, …): events insensitive to any finite number of terms |
| Exchangeable event | An event unchanged by every permutation of finitely many terms |
| Product measure | A measure on a product space under which the coordinates are independent |

## Common misconceptions

- **"Pairwise independent means independent"**: the three-event example above shows otherwise. Pairwise independence does suffice for adding variances in Chebyshev's inequality, and even for the strong law of large numbers (Nasrollah Etemadi, 1981).
- **"A zero–one law gives the answer"**: it says only that the answer is 0 or 1. Whether percolation occurs at the critical value on ℤ³ is open as of 2026; it is known not to occur on ℤ² and in high dimensions.
- **"Independent events are disjoint"**: disjoint events of positive probability are never independent, since P(A ∩ B) = 0 < P(A)·P(B); one excludes the other, which is strong dependence.
