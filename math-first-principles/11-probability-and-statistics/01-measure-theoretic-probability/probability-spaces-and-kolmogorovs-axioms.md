## Essence

A probability space is a triple (Ω, ℱ, P): a set Ω of outcomes, a σ-algebra ℱ of subsets of Ω called events, and a measure P on ℱ with P(Ω) = 1. Andrey Kolmogorov's *Grundbegriffe der Wahrscheinlichkeitsrechnung* (1933) made this the basis of probability, which until then had no agreed foundation beyond finite games. The decisive axiom is countable additivity: it turns limits of events into events and lets the Lebesgue integral do the work, so that expectations, infinite sequences of trials and limit theorems make sense. The price is that not every set of outcomes can be an event: under the axiom of choice no rotation-invariant probability is defined on all subsets of a circle.

## Core tenets

1. **Three axioms make probability a measure of total mass 1.** P(A) ≥ 0 for every event A; P(Ω) = 1; and P(A₁ ∪ A₂ ∪ …) = P(A₁) + P(A₂) + … for pairwise disjoint events. The rules of finite probability (complements, inclusion–exclusion, conditional probability) follow from finite additivity alone, and a finite probability space is the case where Ω is finite and every subset is an event. What is new is countable additivity and the restriction to ℱ.

2. **Infinite experiments force the new framework.** Toss a fair coin forever, so Ω = {0, 1}^ℕ. Each single sequence has probability 0, since it lies in the event "the first n tosses agree with it", of probability 2⁻ⁿ, for every n; yet some sequence occurs, so probabilities cannot be found by adding up outcomes. Instead one assigns 2⁻ⁿ to each cylinder event fixing n tosses and extends to the σ-algebra these generate by Carathéodory's theorem. Kolmogorov's extension theorem does the same for any consistent family of finite-dimensional distributions; this is how every stochastic process is built.

3. **Countable additivity is a continuity axiom.** Given finite additivity, it is equivalent to continuity from below: if A₁ ⊆ A₂ ⊆ …, then P(⋃ₙAₙ) = limₙ P(Aₙ). With Sₙ(ω) the number of heads in the first n tosses, "the proportion of heads tends to 1/2" is built from cylinder events by countable operations, so it is an event (of probability 1, by the strong law of large numbers):

   ```
   { ω : Sₙ(ω)/n → 1/2 }  =  ⋂ₖ ⋃_N ⋂_(n ≥ N) { ω : ∣Sₙ(ω)/n − 1/2∣ < 1/k }
   ```

4. **Countable additivity rules out some appealing "probabilities".** There is no uniform probability on ℕ: if every integer had probability c, then 1 = c + c + c + …, which is 0 or ∞. Natural density, the limiting proportion of {1, …, n} that lies in a set, is only finitely additive. Bruno de Finetti argued for finite additivity, which would allow a fair lottery on ℕ; Kolmogorov's choice prevailed because it makes the limit theorems provable.

5. **Not every set can be an event.** Call two points of the circle equivalent when one is a rotation of the other by a rational fraction of a turn. Choosing one point from each class, which needs the axiom of choice, gives a set V whose countably many rational rotations are pairwise disjoint and cover the circle. A rotation-invariant P on every subset would give each the same value p, and 1 = p + p + … is impossible. This argument of Giuseppe Vitali (1905) is why ℱ is the Borel σ-algebra or its completion. Choice is essential: Robert Solovay (1970) built a model of Zermelo–Fraenkel set theory with dependent choice in which every set of reals is Lebesgue measurable, assuming an inaccessible cardinal is consistent (see [forcing](../../13-structure-and-metamathematics/03-model-theory-and-independence/forcing-and-independence.md) and [large cardinals](../../13-structure-and-metamathematics/03-model-theory-and-independence/large-cardinals.md)).

6. **A σ-algebra is a body of information.** Events are the yes-or-no questions that can be answered, and closure under complements and countable unions lets answers be combined. A smaller σ-algebra 𝒢 ⊆ ℱ models partial information, such as ℱₙ, generated by the cylinders fixing the first n tosses. A filtration ℱ₀ ⊆ ℱ₁ ⊆ ℱ₂ ⊆ … models information growing over time; martingales and stopping times are defined relative to it.

7. **The axioms fix the calculus, not the meaning.** Frequentists read P(A) as a long-run frequency, Bayesians as a degree of belief; both accept the same axioms, and the law of large numbers then proves, inside the theory, that frequencies converge to probabilities. Kolmogorov answered the probability half of Hilbert's sixth problem (1900) and left interpretation to [philosophy](../../15-mathematics-in-context/philosophy-of-mathematics.md). The randomness of a single sequence, on which the axioms are silent, was later defined through [computability](../../13-structure-and-metamathematics/02-computability-and-incompleteness/computable-functions-and-the-church-turing-thesis.md).

## Key concepts

| Term | Meaning |
|---|---|
| Sample space Ω | The set of all possible outcomes ω of an experiment |
| σ-algebra ℱ | A family of subsets of Ω containing Ω, closed under complements and countable unions |
| Event | A member of ℱ: a set of outcomes that is assigned a probability |
| Probability measure P | A countably additive function from ℱ to [0, 1] with P(Ω) = 1 |
| Borel σ-algebra | The smallest σ-algebra on ℝ that contains every interval |
| Cylinder event | An event that depends on only finitely many coordinates of an infinite sequence |
| Null event | An event of probability 0; it need not be empty |
| Almost surely | True outside a null event |
| Filtration | An increasing sequence of σ-algebras: information gathered over time |

## Common misconceptions

- **"Probability 0 means impossible"**: every single infinite coin sequence has probability 0, and one of them happens. Null events can even be uncountable, such as the sequences whose proportion of heads does not tend to 1/2.
- **"Non-measurable sets turn up in applications"**: every set built from intervals by countable unions, intersections and complements is Borel; a non-measurable set needs the axiom of choice.
- **"The axioms say what probability means"**: they constrain every interpretation to obey the same rules, which is why frequentist and Bayesian statistics share one mathematics.
