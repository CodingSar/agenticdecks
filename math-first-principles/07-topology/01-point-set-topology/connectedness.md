## Essence

A space is connected if it cannot be split into two disjoint non-empty open sets. This is the abstract form of "in one piece", and it is exactly what makes the intermediate value theorem work: continuous images of connected spaces are connected, and the connected subsets of ℝ are the intervals. A stronger and more intuitive notion, path-connectedness, asks that any two points be joined by a continuous path. The two agree for open subsets of ℝⁿ and for manifolds, but not in general: the topologist's sine curve is connected without being path-connected. Counting the pieces left after removing a point is the simplest topological invariant, and it already shows that ℝ is not homeomorphic to ℝ².

## Core tenets

1. **The interval [0, 1] is connected, because of the least-upper-bound property.** Suppose [0, 1] = U ∪ V with U and V disjoint, non-empty and open in [0, 1], and 0 ∈ U. Let s = sup {t : [0, t] ⊆ U}. If s ∈ U, openness of U pushes past s unless s = 1, which makes V empty; if s ∈ V, openness of V puts points of V just below s, which lie in U. Completeness is essential: ℚ ∩ [0, 1] splits into the rationals below 1/√2 and those above, both open in it.

2. **Continuous images of connected spaces are connected, and this is the intermediate value theorem.** If f(X) were split by U and V, then f⁻¹(U) and f⁻¹(V) would split X. A subset of ℝ that skips a point c lying between two of its points splits at c, so the connected subsets of ℝ are the intervals. Hence a continuous f: [a, b] → ℝ takes every value between f(a) and f(b). The connected domain is needed: on [0, 1] ∪ [2, 3], the function equal to 0 on the first piece and 1 on the second is continuous and skips 1/2.

3. **Path-connected implies connected, but not conversely.** A path has connected image (tenet 2), so no splitting can separate two points that a path joins. The topologist's sine curve, the graph {(x, sin(1/x)) : 0 < x ≤ 1} together with the segment {0} × [−1, 1], is connected, being the closure of a connected graph. No path joins (0, 0) to the graph: as a path reaches the segment, its first coordinate tends to 0, so its second coordinate takes both values 1 and −1 arbitrarily close to the arrival time and cannot converge.

4. **For open subsets of ℝⁿ and for manifolds, the two notions agree.** There every point has a path-connected neighbourhood, a small ball. The set of points reachable by paths from a fixed point is then open, and so is its complement, so in a connected space it is everything. The same argument works in any locally path-connected space; the sine curve fails because points on its segment have no small path-connected neighbourhoods.

5. **Every space splits uniquely into connected components.** Connected sets that share a point have a connected union, so each point lies in a largest connected set, its component; the components are closed and partition the space. Path components can be smaller: the sine curve has one component and two path components. ℚ and the Cantor set are totally disconnected, with every component a single point, although neither is discrete.

6. **Removing points gives the first invariants.** A homeomorphism f: X → Y restricts to a homeomorphism from X \ {x} onto Y \ {f(x)}, so the number of components left after removing a point is preserved. Removing a point disconnects ℝ but not ℝ², so the two are not homeomorphic, and the same count separates an interval, a circle and the letter Y. Removing a point leaves both ℝ² and ℝ³ connected; telling them apart needs loops, which is where [algebraic topology](../02-algebraic-topology/homotopy-and-the-fundamental-group.md) begins.

7. **Connectedness lets a local property spread.** If the set where a property holds is non-empty, open and closed, then in a connected space it is everything. This proves that a function with zero derivative on a connected open set is constant, that holomorphic functions agreeing near one point of a connected domain agree everywhere, and that a connected group is generated by any neighbourhood of its identity. Such open-and-closed arguments are the topological form of induction.

## Key concepts

| Term | Meaning |
|---|---|
| Connected | Not the union of two disjoint non-empty open sets |
| Path | A continuous map γ: [0, 1] → X |
| Path-connected | Any two points are joined by a path |
| Locally path-connected | Every neighbourhood of a point contains a path-connected neighbourhood of it |
| Component | A maximal connected subset |
| Totally disconnected | Every component is a single point |
| Clopen set | A set that is both open and closed |

The identity theorem for [holomorphic functions](../../09-advanced-analysis/02-complex-analysis/holomorphic-functions.md) and identity components of [Lie groups](../../08-geometry/04-lie-theory/lie-groups-and-lie-algebras.md) rest on clopen arguments.
- **Siblings:** [Compactness](compactness.md) is the other property preserved by continuous images. [Quotients](subspaces-products-and-quotients.md) of connected spaces are connected, and so are products in the product topology, but not in the box topology.

## Common misconceptions

- **"Connected means you can walk from any point to any other."**: That is path-connectedness, which is strictly stronger; the topologist's sine curve is connected but has two path components.
- **"A totally disconnected space is discrete."**: ℚ is totally disconnected, but none of its points is an open set.
