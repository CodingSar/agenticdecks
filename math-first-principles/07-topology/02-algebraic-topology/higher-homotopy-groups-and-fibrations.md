## Essence

The fundamental group records loops, maps of a circle into a space; the n-th homotopy group πₙ records maps of the n-sphere, up to deformation. These groups are abelian from n = 2 on, they are easy to define and very hard to compute: maps of high-dimensional spheres onto low-dimensional ones can be essential, so π₃(S²) ≅ ℤ although S² has no homology above dimension 2. The main computing tool is a fibration, a map that lifts homotopies like a covering map but whose fibres are spaces rather than discrete sets; it yields a long exact sequence tying the homotopy groups of fibre, total space and base together. The Hurewicz and Whitehead theorems then say how homotopy groups relate to homology and when they determine a space.

## Core tenets

1. **πₙ is a group, abelian for n ≥ 2.** An element of πₙ(X, x₀) is a homotopy class of maps from the cube Iⁿ to X sending the whole boundary to x₀; two such maps compose by placing their cubes side by side in the first coordinate, as loops are concatenated. For n ≥ 2 there is a second coordinate to move in, so one cube can be slid round the other, and the two products commute.

2. **Low maps into spheres are trivial, and degree classifies maps of equal dimension.** A map Sᵏ → Sⁿ with k < n can be deformed to a smooth map, which by counting dimensions misses a point, and Sⁿ minus a point is contractible; so πₖ(Sⁿ) = 0 for k < n. Hopf showed that maps Sⁿ → Sⁿ are classified up to homotopy by their degree, the integer they induce on Hₙ, so πₙ(Sⁿ) ≅ ℤ.

3. **A fibration lifts homotopies, and a fibre sequence gives a long exact sequence.** A map p: E → B is a fibration if every homotopy in B lifts to E once its starting point is lifted, the property [covering spaces](covering-spaces.md) have with discrete fibres. With fibre F over the base point, the long exact sequence below holds; exactness means the image of each map is the kernel of the next. The connecting map ∂ lifts a sphere in B to a disc in E and restricts to its boundary, which lies in F.

   ```
   … → πₙ(F) → πₙ(E) → πₙ(B) →∂ πₙ₋₁(F) → … → π₀(E) → π₀(B)
   ```

4. **Covers do not change higher homotopy, and the Hopf fibration computes π₃(S²).** For a cover F is discrete, so πₙ(E) ≅ πₙ(B) for n ≥ 2; since ℝ is contractible, πₙ(S¹) = 0 for n ≥ 2. Send a unit vector (z, w) of ℂ², a point of S³, to the complex line through it, a point of ℂP¹ = S². The fibres are circles, and since πₙ(S¹) = 0 for n ≥ 2 the sequence gives π₃(S²) ≅ π₃(S³) ≅ ℤ, generated by this Hopf map. Any two of its fibres form a Hopf link, linked once. Quaternions and octonions give fibrations S⁷ → S⁴ and S¹⁵ → S⁸, and Adams (1960) proved that such maps of Hopf invariant one exist only from S³, S⁷ and S¹⁵, a result that also shows real division algebras exist only in dimensions 1, 2, 4 and 8.

5. **The Hurewicz theorem: the first non-zero homotopy group is homology.** Sending a map Sⁿ → X to the image of the fundamental class gives a homomorphism πₙ(X) → Hₙ(X). If X is path-connected and πₖ(X) = 0 for all k < n, with n ≥ 2, this map is an isomorphism; for n = 1 it identifies H₁ with π₁ made abelian. So in the first non-trivial dimension, computable [homology](homology.md) finds πₙ.

6. **Whitehead's theorem: a map inducing isomorphisms on every πₙ is a homotopy equivalence, between CW complexes.** CW (closure-finite, weak-topology) complexes are spaces built by gluing cells in order of dimension, and every space is weakly equivalent to one. Both hypotheses matter. A map is required: S² × ℝP³ and ℝP² × S³ have isomorphic homotopy groups, both being covered twice by S² × S³, but different homology. CW structure is required: the Warsaw circle, a circle with one arc replaced by a topologist's sine curve, has every homotopy group trivial yet is not contractible.

7. **Homotopy groups of spheres stabilise, yet remain largely unknown.** Freudenthal's suspension theorem says πₙ₊ₖ(Sⁿ) does not depend on n once n > k + 1; these stable groups are ℤ, ℤ/2, ℤ/2, ℤ/24 for k = 0, 1, 2, 3. Serre proved that πₙ₊ₖ(Sⁿ) is finite for k > 0 except π₄ₘ₋₁(S²ᵐ), which contains one copy of ℤ. Beyond that the groups are irregular, and computing them is a research programme with no general formula, open as of 2026.

## Key concepts

| Term | Meaning |
|---|---|
| πₙ(X, x₀) | Homotopy classes of based maps Sⁿ → X, a group for n ≥ 1 and abelian for n ≥ 2 |
| Fibration | A map with the homotopy lifting property |
| Fibre bundle | A map that is locally a product U × F; a fibration with fibre F |
| Long exact sequence | The sequence linking πₙ of fibre, total space and base |
| Hopf map | S³ → S², the generator of π₃(S²) ≅ ℤ |
| Hurewicz map | πₙ(X) → Hₙ(X), an isomorphism in the first non-trivial dimension |
| CW complex | A space built by attaching cells of increasing dimension |
| Stable homotopy group | πₙ₊ₖ(Sⁿ) for n large, independent of n |

## How it fits

- **Below:** The definition copies [π₁](homotopy-and-the-fundamental-group.md) in higher dimensions; [covering spaces](covering-spaces.md) are the first fibrations; [homology](homology.md) supplies degree and the Hurewicz target.
- **Above:** [Principal bundles](../../08-geometry/02-differential-geometry/vector-bundles-connections-and-characteristic-classes.md) are classified by maps into classifying spaces whose homotopy groups are those of a [Lie group](../../08-geometry/04-lie-theory/lie-groups-and-lie-algebras.md) shifted by one; in [homotopy type theory](../../13-structure-and-metamathematics/01-category-theory/higher-categories-and-homotopy-type-theory.md) types are spaces and identity proofs are paths, and π₁(S¹) ≅ ℤ has a formal proof there.
- **Siblings:** [Cohomology](cohomology-and-poincare-duality.md) is represented by Eilenberg–MacLane spaces, whose only non-zero homotopy group sits in one dimension; the [Euler characteristic](the-euler-characteristic.md) is multiplicative in fibre bundles over simply connected bases, giving χ(S³) = χ(S¹)χ(S²) = 0.

## Common misconceptions

- **"Higher homotopy groups vanish above the dimension, as homology does."**: π₃(S²) ≅ ℤ, and πₙ(S²) is non-zero for infinitely many n.
- **"Spaces with isomorphic homotopy groups are homotopy equivalent."**: Whitehead's theorem needs a single map inducing the isomorphisms; S² × ℝP³ and ℝP² × S³ show the difference.
