## Essence

Which numbers are perfect squares modulo a prime p? Half of the non-zero residues are, and Euler's criterion tests any one of them. The law of quadratic reciprocity says something far less obvious: for odd primes p and q, whether q is a square modulo p is determined by whether p is a square modulo q, with a sign fixed by p and q modulo 4. Two unrelated-looking questions about different moduli turn out to be linked. Euler and Legendre stated the law, Gauss gave the first complete proof and published it in his *Disquisitiones Arithmeticae* (1801), and the search for its generalisations runs through class field theory to the Langlands programme.

## Core tenets

1. **Modulo an odd prime p, exactly (p − 1)/2 non-zero residues are squares.** The map x ↦ x² on the non-zero residues is two-to-one, since x² ≡ y² means p ∣ (x − y)(x + y), so y ≡ ±x. Modulo 11 the squares are {1, 3, 4, 5, 9}. The Legendre symbol (a/p) is 1 if a is a non-zero square modulo p, −1 if it is not, and 0 if p ∣ a.

2. **Euler's criterion: (a/p) ≡ a^((p−1)/2) (mod p).** Write a = gᵏ for a primitive root g. Then a is a square exactly when k is even, and a^((p−1)/2) = g^(k(p−1)/2) is 1 exactly when (p − 1) ∣ k(p − 1)/2, that is when k is even. Consequences: the symbol is multiplicative, (ab/p) = (a/p)(b/p); and −1 is a square modulo p if and only if p ≡ 1 (mod 4), as 5² = 25 ≡ −1 (mod 13) illustrates.

3. **The law and its two supplements.** For distinct odd primes p and q:

   ```
   (p/q) · (q/p) = (−1)^(((p−1)/2) · ((q−1)/2))
   (−1/p) = (−1)^((p−1)/2)          (2/p) = (−1)^((p²−1)/8)
   ```

   So (p/q) = (q/p) unless both p and q are 3 modulo 4, when the signs are opposite; and 2 is a square modulo p if and only if p ≡ ±1 (mod 8).

4. **Reciprocity makes the symbol computable without searching.** Factor, flip and reduce, as in Euclid's algorithm. For (30/37): (2/37) = −1 since 37 ≡ 5 (mod 8); (3/37) = (37/3) = (1/3) = 1; (5/37) = (37/5) = (2/5) = −1; the product is 1, and indeed 17² = 289 ≡ 30 (mod 37). The Jacobi symbol extends (a/n) multiplicatively to odd n and obeys the same law, so no factoring is needed at all.

5. **It turns a condition on p as a modulus into a condition on p modulo something.** Whether 3 is a square modulo p looks like a question about all of ℤ/p, yet reciprocity answers it by congruences: (3/p) = 1 if and only if p ≡ ±1 (mod 12), and (5/p) = 1 if and only if p ≡ ±1 (mod 5). This is the prototype of class field theory: the way a prime p splits in ℚ(√q) depends only on p modulo a fixed number.

6. **There are many proofs, each pointing somewhere different.** Gauss's lemma counts how many of a, 2a, …, ((p−1)/2)a have residues above p/2; Eisenstein turned that count into lattice points under the diagonal of a (p/2) × (q/2) rectangle, which split into two triangles with ((p−1)/2) · ((q−1)/2) points in total. The Gauss sum g = ∑ (a/p)ζᵃ, with ζ a primitive pth root of unity, satisfies g² = (−1/p)p, which shows that √p or √−p lies in the field generated by ζ; this proof is Fourier analysis on ℤ/p. More than two hundred proofs have been published.

7. **Reciprocity decides which primes are values of quadratic forms.** An odd prime p is x² + y² if and only if p ≡ 1 (mod 4); x² + 2y² if and only if p ≡ 1 or 3 (mod 8); x² + 3y² if and only if p = 3 or p ≡ 1 (mod 3). In each case the condition starts as "−1, −2 or −3 is a square modulo p", which reciprocity converts into a congruence. Hilbert's ninth problem (1900) asked for the general reciprocity law in any number field; Artin's reciprocity law (1927) answered it for abelian extensions.

## Key concepts

| Term | Meaning |
|---|---|
| Quadratic residue | A non-zero a that is a square modulo p |
| Legendre symbol (a/p) | 1, −1 or 0 as a is a non-zero square, a non-square or 0 modulo p |
| Euler's criterion | (a/p) ≡ a^((p−1)/2) (mod p) |
| Supplementary laws | The values of (−1/p) and (2/p) |
| Jacobi symbol (a/n) | The product of (a/p) over the prime factors p of an odd n, with multiplicity |
| Gauss's lemma | (a/p) = (−1)^μ, μ the number of a, 2a, …, ((p−1)/2)a above p/2 modulo p |
| Gauss sum | ∑ (a/p)ζᵃ, whose square is ±p |

## Common misconceptions

- **"A Jacobi symbol of 1 means a square"**: (2/15) = (2/3)(2/5) = (−1)(−1) = 1, yet 2 is not a square modulo 3, so not modulo 15.
- **"Gauss discovered the law"**: Euler found it empirically and Legendre stated it with his symbol (1798), with a proof that assumed an unproved result on primes in progressions; Gauss proved it in 1796 and published in 1801.
- **"It is a curiosity of squares"**: cubic and biquadratic analogues exist, and reciprocity laws are a central theme of modern number theory.
