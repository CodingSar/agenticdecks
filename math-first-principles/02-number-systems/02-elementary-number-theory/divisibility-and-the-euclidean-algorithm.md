## Essence

In ℤ you cannot always divide, but you can always divide with a remainder, and that one fact drives elementary number theory. Because gcd(a, b), the greatest common divisor, does not change when a is replaced by its remainder on division by b, repeated division shrinks the problem until the answer is visible: this is Euclid's algorithm, over two thousand years old and still among the fastest algorithms known. Run backwards, it writes the greatest common divisor as an integer combination ax + by, which is Bézout's identity. From that identity come Euclid's lemma, inverses modulo n and the solution of every linear equation in integers.

## Core tenets

1. **Division with remainder: for integers a and b with b > 0 there are unique q and r with a = qb + r and 0 ≤ r < b.** Take r to be the least element of {a − qb : q ∈ ℤ} ∩ ℕ, which is non-empty, so well-ordering supplies it. If r ≥ b, then r − b would be a smaller element, so r < b. Uniqueness: two such pairs give b ∣ (r − r′), with ∣r − r′∣ < b, so r = r′. Here b ∣ a, "b divides a", means a = kb for some integer k.

2. **gcd(a, b) = gcd(b, r) when a = qb + r, so repeated division computes the greatest common divisor.** Any common divisor of a and b divides r = a − qb, and any common divisor of b and r divides a = qb + r, so the two pairs have the same common divisors. The remainders strictly decrease, so the process stops, and the last non-zero remainder is the greatest common divisor:

   ```
   252 = 1·198 + 54
   198 = 3·54  + 36
    54 = 1·36  + 18
    36 = 2·18  + 0        so gcd(252, 198) = 18
   ```

3. **The algorithm is fast: the number of steps grows only with the number of digits.** If rₖ = qrₖ₊₁ + rₖ₊₂, then rₖ ≥ rₖ₊₁ + rₖ₊₂ > 2rₖ₊₂, so the remainders halve every two steps, and the step count is at most about 2 log₂ b. Consecutive Fibonacci numbers are the worst case, and Lamé (1844) showed that the number of divisions is at most five times the number of decimal digits of the smaller input. That is why cryptography can compute greatest common divisors of numbers with hundreds of digits instantly.

4. **Bézout's identity: gcd(a, b) = ax + by for some integers x and y.** Run the algorithm backwards: 18 = 54 − 36 = 54 − (198 − 3·54) = 4·54 − 198 = 4·252 − 5·198. A structural proof: the set I = {ax + by} is closed under addition and under multiplication by integers, and its least positive element d divides a and b by tenet 1 (the remainder of a on division by d lies in I and is smaller than d, so it is 0); any common divisor of a and b divides d, so d is the greatest. In the language of 05, every ideal of ℤ is generated by one element.

5. **Bézout solves every linear equation in integers and gives inverses modulo n.** ax + by = c has an integer solution if and only if gcd(a, b) ∣ c, and if (x₀, y₀) is one solution with d = gcd(a, b), all are x₀ + (b/d)t, y₀ − (a/d)t for t ∈ ℤ. When gcd(a, n) = 1, a solution of ax + ny = 1 gives ax ≡ 1 modulo n, so a has an inverse. It also gives Euclid's lemma: if p is prime and p ∣ ab but p ∤ a, then px + ay = 1, so b = pbx + aby is divisible by p. Finally gcd(a, b) · lcm(a, b) = ab, where lcm is the least common multiple.

6. **The quotients of the algorithm are a continued fraction.** The same divisions give 14/11 = 1 + 1/(3 + 1/(1 + 1/2)). For irrational numbers the expansion never stops, and its truncations, the convergents, are the best rational approximations: for √2 they are 1, 3/2, 7/5, 17/12, …, and each satisfies p² − 2q² = ±1. That is the bridge to Pell's equation in [Diophantine equations](diophantine-equations.md).

7. **The algorithm works wherever a size function makes remainders smaller.** A Euclidean domain is a ring with a division with remainder of this kind: polynomials over a field (by degree) and the Gaussian integers ℤ[i] (by a² + b²) are examples, so they have greatest common divisors, Bézout identities and unique factorisation. The ring ℤ[√−5] has no such division, and unique factorisation fails there (see [primes and unique factorisation](primes-and-unique-factorisation.md)).

## Key concepts

| Term | Meaning |
|---|---|
| Divides, b ∣ a | a = kb for some integer k; b ∤ a means it does not |
| Greatest common divisor | The largest integer dividing both a and b, written gcd(a, b) |
| Coprime | gcd(a, b) = 1 |
| Euclid's algorithm | Replace (a, b) by (b, r) until the remainder is 0 |
| Bézout's identity | gcd(a, b) = ax + by for some integers x, y |
| Extended Euclidean algorithm | Euclid's algorithm run backwards to find x and y |
| Continued fraction | a₀ + 1/(a₁ + 1/(a₂ + ⋯)), the record of the quotients |
| Euclidean domain | A ring with a division with remainder that shrinks a size function |

## Common misconceptions

- **"You need the prime factorisations to find a greatest common divisor"**: Euclid's algorithm never factors, and it is fast even when factoring is hopeless.
- **"Bézout's coefficients are unique"**: they are determined only up to adding multiples of (b/d, −a/d); 15·252 − 19·198 = 18 as well.
- **"Bézout discovered the identity"**: the integer version is implicit in Euclid and was used by Bachet in the seventeenth century; Bézout proved the analogue for polynomials.
