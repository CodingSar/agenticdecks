## Essence

The units modulo n form a finite group, and finiteness alone forces every unit to return to 1 when raised to a fixed power: Fermat's little theorem, aᵖ⁻¹ ≡ 1 (mod p), and Euler's generalisation, a^φ(n) ≡ 1 (mod n). These give fast tests that a number is composite and the arithmetic behind RSA. Modulo a prime more is true: the group of units is cyclic, generated by a single primitive root, so every non-zero residue is a power of one element. Exactly which moduli have primitive roots is a short, complete theorem.

## Core tenets

1. **Euler's theorem: if gcd(a, n) = 1, then a^φ(n) ≡ 1 (mod n).** Here gcd is the greatest common divisor and φ(n) the number of units modulo n. Multiplication by a is invertible, so it permutes the φ(n) units u₁, …, uₖ. The two products ∏ uᵢ and ∏ auᵢ are therefore equal, so a^φ(n) · ∏ uᵢ ≡ ∏ uᵢ, and the product is a unit, so it cancels. For n = p prime, φ(p) = p − 1, and this is Fermat's little theorem, which Fermat stated in 1640 without proof; Euler published proofs, the general form in 1763.

2. **The order of a unit divides φ(n).** The order of a is the least k > 0 with aᵏ ≡ 1. If aᵐ ≡ 1, then dividing m by k leaves a remainder r with aʳ ≡ 1 and r < k, so r = 0 and k ∣ m. This is Lagrange's theorem for groups seen from inside one cyclic subgroup.

3. **Fermat's theorem tests compositeness, but not perfectly.** If 2ⁿ⁻¹ ≢ 1 (mod n), then n is certainly composite, without a factor being found. The converse fails: the Carmichael number 561 = 3·11·17 satisfies aⁿ⁻¹ ≡ 1 for every a coprime to it, because 2, 10 and 16 all divide 560 (Korselt's criterion: n is square-free and p − 1 ∣ n − 1 for every prime p ∣ n). Alford, Granville and Pomerance (1994) proved there are infinitely many Carmichael numbers. The Miller–Rabin test repairs the defect by also checking square roots of 1, and the algorithm of Agrawal, Kayal and Saxena (2002, published 2004) decides primality deterministically in polynomial time.

4. **Modulo a prime p, the units form a cyclic group: primitive roots exist.** For each d ∣ p − 1, if some element has order d, its powers give d solutions of xᵈ ≡ 1, which are all of them because a polynomial modulo p has at most d roots; so exactly φ(d) elements have order d. Hence the number of elements of order d is 0 or φ(d). Every unit has an order dividing p − 1, so these counts add up to p − 1; since ∑ φ(d) over d ∣ p − 1 also equals p − 1, no count is 0; in particular φ(p − 1) elements have order p − 1. For example 3 is a primitive root modulo 7: its powers are 3, 2, 6, 4, 5, 1.

5. **Primitive roots exist modulo n if and only if n is 1, 2, 4, pᵏ or 2pᵏ, with p an odd prime.** If g is a primitive root modulo p, then g or g + p is one modulo p², and it remains one modulo every pᵏ; the Chinese remainder theorem (CRT) then handles 2pᵏ, since (ℤ/2)ˣ is trivial. Modulo 2ᵏ with k ≥ 3, x² ≡ 1 has four solutions, impossible in a cyclic group. If n = ab with a, b > 2 coprime, both φ(a) and φ(b) are even, so every unit has order dividing lcm(φ(a), φ(b)), the least common multiple, which is less than φ(n).

6. **Which numbers are primitive roots is subtle.** Artin conjectured in 1927 that 2, and indeed any integer other than −1 that is not a perfect square, is a primitive root modulo infinitely many primes. The conjecture is open as of 2026; Hooley (1967) proved it assuming the generalised Riemann hypothesis.

7. **Public-key cryptography rests on this group theory.** In RSA (Rivest, Shamir and Adleman, 1977), n = pq is public, and so is e with gcd(e, φ(n)) = 1; the secret d satisfies ed ≡ 1 (mod φ(n)), and Euler's theorem gives (mᵉ)ᵈ ≡ m (mod n). Knowing φ(n) is as good as knowing the factors, because p and q are the roots of x² − (n − φ(n) + 1)x + n. Diffie–Hellman key exchange (1976) publishes a primitive root g modulo p and relies on the difficulty of recovering k from gᵏ, the discrete logarithm. Shor (1994) showed that a large quantum computer would solve both problems efficiently.

## Key concepts

| Term | Meaning |
|---|---|
| Fermat's little theorem | aᵖ⁻¹ ≡ 1 (mod p) when p ∤ a |
| Euler's theorem | a^φ(n) ≡ 1 (mod n) when gcd(a, n) = 1 |
| Order of a modulo n | The least k > 0 with aᵏ ≡ 1 (mod n) |
| Primitive root | A unit whose order is φ(n), so its powers give every unit |
| Carmichael number | A composite n with aⁿ⁻¹ ≡ 1 for every a coprime to n |
| Discrete logarithm | Given g and gᵏ modulo p, the exponent k |
| Wilson's theorem | (p − 1)! ≡ −1 (mod p), from pairing each unit with its inverse |

## Common misconceptions

- **"If aⁿ⁻¹ ≡ 1 (mod n), then n is prime"**: Carmichael numbers such as 561 pass for every coprime base.
- **"Every modulus has a primitive root"**: modulo 8 the units 1, 3, 5, 7 all square to 1, so none generates.
- **"Breaking RSA is proved to be as hard as factoring"**: factoring breaks RSA, but no proof of the converse is known; the security rests on unproved hardness assumptions.
