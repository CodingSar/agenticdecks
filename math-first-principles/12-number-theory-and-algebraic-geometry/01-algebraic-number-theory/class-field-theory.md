## Essence

Galois theory matches the extensions of a field with subgroups of a Galois group, but it does not say what the extensions of ℚ, or of a number field K, actually are. Class field theory answers this completely for abelian extensions, those with commutative Galois group: they are classified by data inside K itself, namely groups of ideals modulo principal ideals with congruence conditions. The bridge is the Frobenius element, which turns the way a prime splits in an extension into an element of the Galois group. Quadratic reciprocity, which looked like a coincidence between two primes, becomes a special case of a single map, the Artin map. Its conjectural non-abelian generalisation is the Langlands programme.

## Core tenets

1. **Frobenius elements turn splitting into group elements.** Let L/K be a Galois extension and 𝔭 a prime of K that does not ramify. For a prime 𝔓 of L above 𝔭, there is a unique σ in the Galois group with σ(x) ≡ x^(N𝔭) mod 𝔓 for all integers x of L, because the Galois group of the residue field extension is generated by the power map. When the group is abelian, σ does not depend on 𝔓; call it Frob_𝔭. The prime 𝔭 splits completely exactly when Frob_𝔭 = 1. Chebotarev's density theorem says every group element occurs as a Frobenius for a positive proportion of primes.

2. **Over ℚ, every abelian extension is cyclotomic (Kronecker–Weber).** Every finite abelian extension of ℚ lies inside some ℚ(ζ_m), where ζ_m is a primitive m-th root of unity. In ℚ(ζ_m), whose Galois group is (ℤ/m)^×, the Frobenius of a prime p ∤ m is simply p mod m, since it sends ζ_m to ζ_mᵖ. So how p splits depends only on p mod m. For example √5 = ζ − ζ² − ζ³ + ζ⁴ with ζ = ζ₅, so ℚ(√5) ⊆ ℚ(ζ₅) and the splitting of p in ℚ(√5) depends only on p mod 5. Kronecker stated the theorem; complete proofs came later, from Weber and Hilbert.

3. **Artin reciprocity is the general law.** For an abelian extension L/K there is a modulus 𝔪, built from the ramified primes, such that the Artin map 𝔭 ↦ Frob_𝔭 extends to a surjective homomorphism from the ray class group mod 𝔪 onto Gal(L/K), whose kernel is generated by norms from L. So splitting in L is governed by congruence conditions in K. Artin proved this in 1927. For K = ℚ the ray class group mod m is (ℤ/m)^× and the map is the one in tenet 2.

4. **Quadratic reciprocity is the smallest case.** For an odd prime q, put q∗ = (−1)^((q−1)/2)·q, so that ℚ(√q∗) is the unique quadratic field inside ℚ(ζ_q). For an odd prime p ≠ q, compute the Frobenius of p in ℚ(√q∗) in two ways. Directly, it is trivial exactly when q∗ is a square mod p, that is, when the Legendre symbol (q∗/p) = 1. Through ℚ(ζ_q), it is the image of p mod q under (ℤ/q)^× → {±1}, which is (p/q). So (q∗/p) = (p/q), and this is quadratic reciprocity.

5. **The Hilbert class field realises the class group.** Every number field K has a largest abelian extension H that is unramified at every prime and at infinity, and Gal(H/K) ≅ Cl(K) through the Artin map. A prime ideal of K splits completely in H exactly when it is principal. For K = ℚ(√−5), with class number 2, H = ℚ(√−5, i). Combining this with the splitting of p in H yields the classical theorem that an odd prime p ≠ 5 is x² + 5y² if and only if p ≡ 1 or 9 mod 20.

6. **The existence theorem makes it a dictionary.** Takagi proved that every subgroup of finite index in a ray class group, containing the principal ideals congruent to 1 mod 𝔪, arises from exactly one abelian extension. Larger subgroups correspond to smaller fields, so the correspondence reverses inclusion, like Galois theory. A local version over each ℚ_p classifies abelian extensions of local fields by subgroups of ℚ_p^×, and the global theory is glued from the local ones using the ideles.

7. **Beyond abelian, the doorway to Langlands.** For non-abelian extensions no description by ideals of K exists. Yet splitting is still governed by something: for x³ − x − 1, whose splitting field has Galois group S₃, and a prime p ≠ 23, the number of roots mod p is a_p + 1, where the aₙ are the coefficients of

   ```
   q·∏ (1 − qⁿ)(1 − q^(23n)) = ∑ aₙqⁿ = q − q² − q³ + q⁶ + q⁸ − ⋯     (product over n ≥ 1)
   ```

   This series is a modular form of weight 1 and level 23. The [Langlands programme](../04-elliptic-curves-and-modular-forms/the-langlands-programme.md) conjectures that every Galois representation is governed this way, with class field theory as the one-dimensional case.

## Key concepts

| Term | Meaning |
|---|---|
| Abelian extension | A Galois extension with commutative Galois group |
| Frobenius element Frob_𝔭 | The Galois element acting as x ↦ x^(N𝔭) modulo a prime above 𝔭 |
| Ray class group mod 𝔪 | Ideals prime to 𝔪 modulo principal ideals (α) with α ≡ 1 mod 𝔪 |
| Artin map | Sends each unramified prime to its Frobenius |
| Kronecker–Weber theorem | Every abelian extension of ℚ is inside a cyclotomic field |
| Hilbert class field | Largest unramified abelian extension; Galois group Cl(K) |
| Existence theorem | Every finite-index congruence subgroup comes from an abelian extension |

## Common misconceptions

- **"Class field theory constructs the abelian extensions explicitly"**: explicit generators are known for ℚ (roots of unity) and imaginary quadratic fields (values of elliptic and modular functions, complex multiplication). Hilbert's twelfth problem, to do this for every number field, is open in general as of 2026.
- **"It is about the class group only"**: the class group gives the unramified extensions; ramified ones need ray class groups.
