## Essence

Unsupervised learning finds structure in data without labels: groups of similar items, a few directions that explain most variation, or the probability distribution the data came from. Since unlabelled data is vastly more plentiful than labelled data, this is where most of the information in the world sits. The unifying idea is **compression**: data with structure can be described more briefly than random data, and finding that shorter description (clusters, low-dimensional coordinates, a probability model) is finding the structure. Self-supervised learning, which turns raw data into its own prediction targets, is the modern form of this idea and the basis of large pre-trained models.

## Core tenets

1. **Without labels, the objective defines what "structure" means.** Clustering minimises within-cluster distance; dimensionality reduction minimises reconstruction error; density estimation maximises likelihood. Different objectives find different structure in the same data, and there is no single right answer to check against. Evaluation is therefore harder than in supervised learning and often indirect: does the learned structure help a downstream task?

2. **k-means alternates two easy steps.** Assign each point to its nearest centroid, then move each centroid to the mean of its points. Each step lowers the within-cluster sum of squares, so the algorithm converges, but only to a local optimum that depends on initialisation. It assumes roughly spherical clusters of similar size, an inductive bias that fails on elongated or nested shapes.

3. **Mixture models make clustering probabilistic.** A Gaussian Mixture Model (GMM) says each point was generated by first picking a cluster, then sampling from that cluster's Gaussian. Expectation-Maximisation (EM) alternates computing soft cluster memberships (E-step) with re-fitting each Gaussian to its weighted points (M-step), monotonically increasing likelihood. k-means is the limit of EM with hard assignments and equal spherical variances.

4. **Principal Component Analysis (PCA) finds the directions of greatest variance.** The top k eigenvectors of the data's covariance matrix (equivalently, the top right singular vectors of the centred data matrix) give the best rank-k linear approximation in squared error. Projecting onto them compresses, denoises and visualises data. PCA is linear; manifold methods and autoencoders capture curved structure.

5. **Autoencoders learn compression with neural networks.** An encoder maps x to a low-dimensional code z and a decoder reconstructs x from z; training minimises reconstruction error. A linear autoencoder with squared loss recovers the PCA subspace. With non-linear layers it learns curved manifolds, and the variational autoencoder adds a probabilistic prior on z that turns it into a [generative model](../04-advanced-paradigms/generative-models.md).

6. **Prediction is compression.** A model that assigns probability p to data can encode it in about −log₂ p bits (Shannon). Maximising likelihood is minimising code length, so a better density model is literally a better compressor. This is why next-token prediction on text, a purely self-supervised objective, forces a model to capture grammar, facts and reasoning patterns: they all shorten the description of text.

7. **Self-supervision manufactures labels from structure in the data.** Mask a word and predict it, predict the next token, or train two augmented views of an image to have similar embeddings (contrastive learning). The resulting representations transfer to many downstream tasks with few labels. As of the mid-2020s, almost all large "foundation" models are pre-trained this way and adapted later with small amounts of labelled data.

## Key concepts

| Term | Meaning |
|---|---|
| Clustering | Partitioning data into groups of similar items |
| Centroid | Mean point of a cluster |
| Gaussian mixture | Density modelled as a weighted sum of Gaussian components |
| EM algorithm | Alternating soft assignment and parameter re-fitting to maximise likelihood with latent variables |
| Principal component | Direction of maximum remaining variance; an eigenvector of the covariance matrix |
| Embedding | Learned vector representation where geometry reflects similarity |
| Autoencoder | Network trained to reconstruct its input through a bottleneck |
| Self-supervised learning | Training on targets derived automatically from unlabelled data |
| Contrastive learning | Pulling embeddings of related views together and unrelated ones apart |

## Common misconceptions

- **"Clusters found by an algorithm are real categories."** k-means always returns k clusters, even on uniformly random data. Cluster validity must be argued separately.
- **"PCA finds the important features."** It finds the high-variance directions, which may be noise or scale artefacts. Standardise features first and check what the components mean.
- **"Self-supervised means no human input."** The choice of objective, augmentation and data source is a strong human-designed inductive bias.
